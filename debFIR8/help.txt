Tutorial: How to use this tool (debFIRE) — debFIRE has been built for safe, beginner-friendly brute-force attacks. Here’s how it works: it asks you for the target’s Instagram username, and you enter it. Next, it asks for a password list — you can create your own password list with the deb.p tool — and a proxy list.
